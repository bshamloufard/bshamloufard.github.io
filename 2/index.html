Part 1.1: Convolutions from Scratch!

Here are my implementations for a 4-loop and a 2-loop convolution.

4-Loop Convolution

def convolution_4loops(image, kernel, padding=True):
    """Convolution implementation using four nested for loops with padding."""
    img_height, img_width = image.shape
    kernel_height, kernel_width = kernel.shape
    
    pad_h = kernel_height // 2
    pad_w = kernel_width // 2
    
    if padding:
        padded_image = np.zeros((img_height + 2*pad_h, img_width + 2*pad_w))
        padded_image[pad_h:pad_h+img_height, pad_w:pad_w+img_width] = image
        output = np.zeros((img_height, img_width))
    else:
        padded_image = image
        output = np.zeros((img_height - kernel_height + 1, img_width - kernel_width + 1))
    
    output_height, output_width = output.shape
    
    # Four nested loops: output image (i,j) and kernel (ki,kj)
    for i in range(output_height):
        for j in range(output_width):
            conv_sum = 0.0
            for ki in range(kernel_height):
                for kj in range(kernel_width):
                    img_i = i + ki if not padding else i + ki
                    img_j = j + kj if not padding else j + kj
                    conv_sum += padded_image[img_i, img_j] * kernel[ki, kj]
            output[i, j] = conv_sum
    
    return output

2-Loop Convolution (Optimized)

def convolution_2loops(image, kernel, padding=True):
    """Convolution implementation using two nested for loops with vectorized operations."""
    img_height, img_width = image.shape
    kernel_height, kernel_width = kernel.shape
    
    pad_h = kernel_height // 2
    pad_w = kernel_width // 2
    
    if padding:
        padded_image = np.zeros((img_height + 2*pad_h, img_width + 2*pad_w))
        padded_image[pad_h:pad_h+img_height, pad_w:pad_w+img_width] = image
        output = np.zeros((img_height, img_width))
    else:
        padded_image = image
        output = np.zeros((img_height - kernel_height + 1, img_width - kernel_width + 1))
    
    output_height, output_width = output.shape
    
    # Two nested loops: only for output image positions
    for i in range(output_height):
        for j in range(output_width):
            # Extract image region that matches kernel size
            region = padded_image[i:i+kernel_height, j:j+kernel_width]
            # Vectorized element-wise multiplication and sum
            output[i, j] = np.sum(region * kernel)
    
    return output

The SciPy implementation is significantly faster due to its use of highly optimized algorithms (like FFT-based convolution). My custom 2-loop implementation is much faster than the 4-loop version because it leverages NumPy's vectorized operations, which are implemented in C and are much more efficient than Python loops.

Part 1.2: Finite Difference Operator

To detect edges, I first computed the partial derivatives of the image in the x and y directions. This was done by convolving the image with finite difference operators, specifically Dx=[1,0,-1] for vertical edges and Dy=[[1],[0],[-1]] for horizontal edges. From these, I calculated the gradient magnitude as √(Dx² + Dy²) to get an overall measure of edge strength at each pixel. To create the final binary edge map, I binarized the magnitude image using a normalized threshold, set to 17% of the maximum gradient value. This threshold of 0.17 was chosen carefully through experimentation: a lower value resulted in distracting noise (small white dots) appearing across the image, while a higher value failed to capture some of the important structural edges that define the cameraman.

Part 1.3: Derivative of Gaussian (DoG) Filter

The edge detection from the finite difference operator was effective but noisy. To improve this, I first smoothed the image by convolving it with a Gaussian filter, which I created using cv2.getGaussianKernel(). Applying the difference operators to this blurred image produced much cleaner edge maps. To make this process more efficient, I also created Derivative of Gaussian (DoG) filters. This was done by convolving the Gaussian filter itself with the Dx and Dy finite difference operators. These new DoG filters allow for smoothing and differentiation in a single convolution step. As the results show, both the two-step (blur then differentiate) and single-step (DoG) methods produce identical, cleaner results compared to the noisy output from Part 1.2.

Part 2: Fun with Frequencies!

Part 2.1: Image "Sharpening"

I implemented the unsharp masking technique to sharpen images. The core idea is to exaggerate edges and fine details. My approach follows the formula I_sharp = I + α(I - I_blurred). First, I create a blurred, low-frequency version of the image using a Gaussian filter. Then, I subtract this blurred version from the original image to isolate the high-frequency components (the details). Finally, I add these high-frequency details back to the original image, scaled by an amplification factor, alpha, to enhance their strength and create a sharper final result.

Part 2.2: Hybrid Images

Following the approach described by Oliva, Torralba, and Schyns (2006), I created hybrid images that produce different interpretations at varying viewing distances. This fascinating visual illusion is achieved by combining the high-frequency components of one image with the low-frequency components of another. The high frequencies are visible up close, while the low frequencies dominate from a distance.

Messi, the GOAT (σ_low=8.0, σ_high=4.0)

For this hybrid, the low-pass filter (sigma_low=8.0) was applied to the image of Messi, preserving the broad shapes, while the high-pass filter (sigma_high=4.0) was applied to the goat, capturing its fine texture. These sigma values were chosen after experimentation to strike the perfect balance. If Messi's sigma was too low, his image would be too clear up close; for the goat, a different sigma would have either obscured its features or overwhelmed Messi's from a distance.

Part 2.3: Gaussian and Laplacian Stacks

Following the 1983 paper by Burt and Adelson, I implemented Gaussian and Laplacian stacks to decompose an image into different frequency bands. Unlike image pyramids, which downsample at each level, stacks maintain the full resolution throughout. I first created the Gaussian stack by iteratively applying a Gaussian blur. Then, the Laplacian stack was generated by finding the difference between adjacent levels of the Gaussian stack. This process, which enables perfect reconstruction by summing the levels, is visualized below, recreating the results from Figure 3.42 in the Szeliski textbook.

Part 2.4: Multiresolution Blending

Using the Gaussian and Laplacian stacks from the previous part, I implemented a multi-resolution blending algorithm. This powerful technique creates seamless composites by blending images across different frequency bands. The process involves generating Laplacian stacks for the two source images and a Gaussian stack for the blending mask. Each level of the new blended Laplacian is a combination of the two source stacks, weighted by the corresponding level of the mask's Gaussian stack. Finally, collapsing this new stack reveals the smoothly blended final image, effectively hiding the seam.

What I Learned

The most important thing I learned from this project is the power of thinking about images in the frequency domain. Before, I mostly thought about images as a grid of pixels. This project showed me that by decomposing an image into its different frequency bands, we can perform powerful manipulations like sharpening, creating hybrid images that fool our perception, and seamlessly blending images together. It was fascinating to see how fundamental concepts like Gaussian filters are the building blocks for so many advanced and creative techniques in computational photography. This project provided a much deeper intuition for how and why these methods work.
